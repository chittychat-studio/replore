# Privacy

*Last updated: 24 October 2026 (an "Add Replore on Google" link in the footer opens Google's source preferences page, only if you click it; earlier: Replore Pro is now sold with Stripe: the key is checked with Stripe, subscription status only, and the new /pro page asks Stripe whether your checkout is paid to show your key; earlier: Replore Pro key sent only to our function, never stored or logged; the optional security-log hook described as a no-op unless switched on; earlier: the Trust sort runs the existing safety check for the top five cards; the Explore links are now the "Look inside" tools in a card's Details, same five sites; earlier: the plugin can run the "Safe to build on?" check too; earlier: "Safe to build on?" check on result cards; earlier: DeepWiki added to the Explore links; Explore links on result cards; Cloudflare Web Analytics page-view counts disclosed; off-topic repos move down, not hidden; optional tips via Stripe; bot check switched on; feedback goes by email to Cardzo). This describes how Replore handles data as built. It is not legal advice.*

**Short version:** Replore has no account and no database, and stores nothing you type. Our host counts page views
with Cloudflare Web Analytics, a cookieless page-view counter that never sees what you type. The people who
make Replore never keep your ideas, searches or plans. Your search words go to GitHub to run the search and — on the
web page only — to an AI provider that checks which results fit. Nothing you type is kept by us; if the AI check fails, we
keep only the error type and time, to fix it.

## Web page (replore.cardzo.co.in, also replore.pages.dev)

| What | Where it goes | Why |
|---|---|---|
| Your search words (and words taken from a plan you upload) | **GitHub's API** (`api.github.com`), with your IP address | To run the search. The trending carousel and gallery also ask GitHub's API for popular repos (no words from you), at most once per list every 30 minutes. GitHub's handling is covered by the [GitHub Privacy Statement](https://docs.github.com/site-policy/privacy-policies/github-general-privacy-statement). |
| Your search words, and the names, descriptions and topics of up to 30 repos found | **Our relevance check** (a small Cloudflare Pages Function) → **Cloudflare Workers AI** (the AI that judges fit, run by Cloudflare, which also hosts this site), or, when that is unavailable or over its daily limit, **Groq** (the same check at another AI provider) | To move repos that don't fit what you're building to the end of the list, under "Less likely to fit". The function stores nothing you send. When a check fails, it records only the error type, how long it took and when — never your search words, the repos, your IP address or anything else you typed — so we can fix problems. Workers AI processes the request under [Cloudflare's privacy policy](https://www.cloudflare.com/privacypolicy/); Groq under [its own](https://groq.com/privacy-policy/). Cloudflare may keep standard request logs under its policy. We keep nothing you type. To avoid re-running the same check, the AI's answer (only which repos don't fit) is cached for an hour, keyed by a one-way fingerprint of the search and the repo list, never the words themselves; for our own built-in example searches, for up to a day. If the check is unavailable, you get the unfiltered keyword results instead. |
| Only when switched on (SPEC RS42): your search words and the same repo names, descriptions and topics | **Cloudflare Workers AI** embedding model (same provider as above), and for the repo index, **Cloudflare Vectorize** (which holds public repo names and descriptions only) | To rank repos by meaning as well as by matching words, and to suggest public repos the keyword search missed. Nothing you type is stored; every suggested repo is checked live on GitHub before it is shown. If this step fails, only an error code and how long it took are logged (SPEC RS42b), never your words. In the plugin this only happens if you add `--semantic`, which sends your project description to Replore's server for this one purpose; that plugin route stays off unless we switch it on separately, and it answers only callers holding Replore's private plugin key. |
| Browser signals Cloudflare Turnstile uses to tell people from bots (the bot check is on) | **Cloudflare Turnstile** (`challenges.cloudflare.com`), loaded when you search | To stop automated scripts from using up the shared free AI allowance. It usually needs no click. Our function passes your IP address to Cloudflare's verification service along with the Turnstile token. Cloudflare handles it under its [privacy policy](https://www.cloudflare.com/privacypolicy/). |
| Your IP address and browser details, when the page loads | **Cloudflare Pages** (hosts the page) | To deliver the page. Loading the page doesn't reveal what you search: searches are never put in the page address. (The relevance check in the row above does send your search words to Cloudflare.) Fonts and scripts are served from the same site — no request goes to Google Fonts or any other CDN. |
| The page address (never your searches, which are not in it), the referring site, your browser, operating system and device type, your country, and page-load timings | **Cloudflare Web Analytics**, a cookieless, privacy-first page-view counter run by Cloudflare. Our host (Cloudflare Pages) has it switched on for this site, and the page loads its script from `static.cloudflareinsights.com`, which reports to `cloudflareinsights.com` | So we can see how many people visit and whether the page loads fast. It sets no cookie, stores nothing on your device, does not fingerprint you, never sees what you type or search, and gives us only totals. Cloudflare handles it under its [privacy policy](https://www.cloudflare.com/privacypolicy/) (see also [Cloudflare Web Analytics](https://www.cloudflare.com/web-analytics/)). |
| Your last search, results and filters, your light/dark choice, a 30-minute copy of the public trending lists, and — only when the AI check's daily allowance is used up — the time it resets | **Your browser only** (local storage on your device) | So a refresh brings your results back, the trending carousel doesn't re-ask GitHub on every visit, and the page doesn't retry the AI check before it resets. Use the clear button in the search bar, or the Replore logo, to delete it, or clear this site's data in your browser. |
| A Replore Pro key, only if you save one (on the page's Pro window or the `/pro` page, which also saves it for you after you buy; stored in your browser's local storage as `replore.key`) | **Your browser**, which sends it with each relevance check to **our relevance check** (same site, never in the page address); the function asks **Stripe** (`api.stripe.com`, which sells Pro for Cardzo) only whether the key's subscription is active, under [Stripe's privacy policy](https://stripe.com/privacy). When you click a buy button on our site, the page puts a random one-time marker in this tab's session storage (`replore.checkout`, nothing about you in it); `/pro` reads and deletes it on your return, and saves the key by itself only when the marker is there and no other key is saved, otherwise it asks | So a Pro key's rights apply on the web too (today: your checks skip the per-address limit). We never store the key and never log it: it is a signed token, so no key list exists; the function keeps only a one-way fingerprint and the yes/no answer in memory for 10 minutes, and a check or claim is logged as a code only. What you pay with and your billing details stay with Stripe; we see only that a subscription is active. The key is never sent with the feedback form or to any other site. Remove key, or clear this site's data, to delete it. |

| Nothing, unless you open **Is it safe to build on?** on a result card, or pick the **Trust (top 5)** sort (which runs the same check for the top five cards) | The repo's public name goes to **GitHub's API** from your browser (with your IP address) for its community files, latest release and good-first-issue count. pixels, ads or cookies.

## Plugin, MCP server and script (on your computer)

- Everything runs on your own computer. Your search words go to **GitHub's API** (as above). Nothing is sent to us.
- **Safe to build on? (only when you ask for it).** If you or your agent run the trust check (`scripts/trust.py`,
  `scout.py --trust`, or the MCP tool `check_repos`), your computer sends the public names of up to 5 repos (and
  their programming language) to **GitHub's API**, **OpenSSF Scorecard** (`api.securityscorecards.dev`) and **Google's
  deps.dev** (`api.deps.dev`, vulnerability data from **OSV.dev**), with your IP address, under their own terms. Never
  your search words. `GITHUB_TOKEN`, if set, goes to GitHub only.
- Your AI agent and its AI provider (for example Anthropic, OpenAI or Google) process your conversation under
  **their own** terms. That is between you and them; Replore doesn't receive it.
- If you set `GITHUB_TOKEN`, it is sent only to GitHub and is never printed or logged.
- **Replore Pro key (only if you set one).** If you set `REPLORE_KEY` (or `REPLORE_PLUGIN_KEY`) and ask for meaning
  ranking (`--semantic`, or `semantic` in the MCP tool), the key is sent, with your project description, only to
  Replore's own function (`replore.cardzo.co.in`), never to any other host and never through a redirect. The function
  checks the key's signature itself, then asks **Stripe** (`api.stripe.com`, which sold it, under
  [Stripe's privacy policy](https://stripe.com/privacy)) only whether its subscription is active, and keeps only a one-way fingerprint of it and the
  yes/no answer in memory for 10 minutes. We never store the key and never log it; a failed or refused check is
  logged as a code only.
- **Optional security log (Claude Code plugin only) — off by default.** Nothing from your prompts is stored unless
  you turn this on. If you set the environment variable `REPLORE_SECURITY_LOG` (to `1` for the default location, or
  to a file path), a safety hook checks each prompt you send in Claude Code while the plugin is enabled; when one
  matches a prompt-injection or harmful-request pattern, it writes one line — time, session id, which pattern
  matched, and the **first 200 characters** of that prompt — to `~/.replore/security.log` (or your path) **on your
  computer**. It is never sent anywhere. Unset the variable to stop; delete the file at any time. This log is an
  audit trail, not a protection: Replore's safety rules work the same whether it is on or off. The MCP server and
  the script never write it. While the variable is unset, the hook is a no-op: it starts, exits at once and does not
  read your prompt. It runs as `python3`; on Windows without `python3` it does not start at all (nothing is logged),
  and you can change the installed hook's `"command"` to `python` in its `hooks/hooks.json` if you want the log.
